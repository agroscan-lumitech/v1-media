The server, endpoint by endpoint.

A readable reference to the AgroScan backend's server.js — frameworks, middleware, and every route it exposes.

This page documents the AgroScan backend server (server.js) — an Express + MySQL application that is the operational core connecting the mobile/web frontend, the AI recommendation layer, and the developer administration tools.

Middleware stack

  • cors() — handles external requests from AgroScan web and mobile clients.
  • bodyParser.json() — parses JSON request bodies.
  • multer.memoryStorage() — in-memory image uploads (e.g. profile photos).
  • child_process & os — power the system health/monitoring endpoints.

Database connection

A mysql2/promise connection pool reads its credentials from environment variables (DB_HOST, DB_USER, DB_PASSWORD, DB_NAME) — making the server portable across any MySQL-compatible host without code changes.
