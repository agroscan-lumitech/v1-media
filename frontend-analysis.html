The Org Portal: where a farmer meets AgroScan.

A module-by-module breakdown of the farmer-facing frontend — navigation, authentication, soil analytics, AI chat, AgroPedia and AgroShop.

The AgroScan Frontend is the user-facing web layer of the ecosystem, developed by Abhinav Ranjan & Team. It integrates soil testing, AI chat, Agropedia, AgroAwareness and AgroShop into a single, accessible, modular platform — purpose-built to be responsive, multilingual and data-rich.

Navigation & Layout

Reusable HTML templates with dynamically managed header/footer, and CSS Grid/Flexbox for adaptive, mobile-friendly layouts.

Authentication System

Login and signup with form validation, integrated with the backend authentication API and browser-based session persistence.

Soil Test & Analytics

A soil-test form collects temperature, pH and moisture data, submitted via AJAX to the backend AI engine for instant feedback.

Chat Module

Real-time chat connecting to AgroScan's AI model endpoint, with message logs, typing animation and offline caching.

AgroPedia & AgroAwareness

Structured HTML articles with images and quick links — an educational content repository for farmers and students.

AgroShop

Lists seeds, fertilizers and tools; handles cart operations, payment redirection and confirmation with JS/CSS-driven UX.

PLANNED ENHANCEMENTS
  • Progressive Web App (PWA) support for offline functionality.
  • Dark mode and a theme selector for accessibility.
  • Map-based visualisation of local climate and soil reports.
  • AgroScan AI voice assistant integrated into chat.html.
  • Secure UPI & wallet payment gateways in AgroShop.
  • An admin analytics portal for large-scale farm data review.
